1. Overview & Architecture

The College Admin Role-Based Access Control (RBAC) System introduces granular sub-role management within the college_admin tier. Rather than every college admin having monolithic full access, admins can now hold multiple specific functional roles (e.g. Accounts & Finance, COE / Exam Cell, Academic Affairs, Library Management, HR / Leave Manager, LMS Content).

Core Architectural Highlights:
  • Multi-Role Assignment: An admin user can hold multiple roles simultaneously (e.g. both coe AND accounts). Permitted section access is the union of all assigned roles.
  • Global Role Templates (IT Portal): IT Admins can create global role templates that act as baseline configurations available across all institutions.
  • College-Specific Customization & Naming: IT Admins can customize role display names specifically for any college (e.g., renaming COE / Exam Cell to Examination & Evaluation Cell).
  • Tab Visibility Access Matrix: College Super Admins can toggle feature access for each role on a granular matrix grid.
  • Configuration Lock & Security: College Super Admins can Lock the configuration. When locked, backend APIs block write operations with HTTP 423 Locked and frontend buttons are disabled.
  • Global Toast Notifications: Integrated with ErrorPopupContext for floating toast alerts across all operations.

3. Step-by-Step End-to-End Testing Guide

Test Scenario 1: IT Portal — Create Global Custom Role Template
  1. Log in to the IT Portal at http://localhost:5173/it-admin (Credentials: admin@eduspace.in / admin123).
  2. Navigate to the Custom Role Builder tab in the navigation bar.
  3. Under Global System & Custom Role Templates, click + Create Global Role.
  4. Enter Role Label: Principal's Office, Description: Executive oversight and departmental notices. Select default tab permissions (e.g. Notice Board, Academic & Depts).
  5. Click Create Global Role. Verify a floating success toast appears and the role card displays under Global Templates.
Test Scenario 2: IT Portal — Customize Role Name for a Specific College
  1. In the Custom Role Builder tab, scroll down to College Role Assignments & Customizations.
  2. Select the target college from the dropdown (e.g. Institute of Engineering Management).
  3. Locate the COE / Exam Cell role card and click the Edit (Pencil) icon.
  4. Enter the new display name: Examination & Evaluation Cell and click Save Custom Name.
  5. Verify the role card updates to display the custom name.
Test Scenario 3: College Admin Portal — Multi-Role Staff Assignment
  1. Log in as College Super Admin at http://localhost:5173/dashboard/admin-roles.
  2. Notice the top ← Back to Dashboard button leading to /dashboard.
  3. Click + Add / Assign Admin.
  4. Enter Name, Email, Password, and check multiple roles (e.g. COE / Exam Cell AND HR / Leave Manager).
  5. Click Save Admin. Verify the user appears in the table with dual-role pill badges.
Test Scenario 4: College Admin Portal — Tab Visibility Matrix
  1. On http://localhost:5173/dashboard/admin-roles, switch to the Tab Visibility Matrix sub-tab.
  2. Locate the customized role (e.g. Examination & Evaluation Cell) and check/uncheck feature tabs.
  3. Click Save Matrix Changes. Verify the floating green success popup appears.
Test Scenario 5: Strict Configuration Lock & Security Verification
  1. Click the top-right Lock Configuration button.
  2. Observe the amber status banner: 🔒 Tab & Role Configuration is Currently Locked.
  3. Verify that Add / Assign Admin, Edit (pencil), and Delete (trash) buttons become disabled.
  4. Attempt to click any action: Verify an error popup appears: "Configuration is locked! Unlock it before modifying admin roles."
  5. Click Unlock Configuration to unfreeze. Verify write controls become active again.

4. API Endpoints Summary

Method Endpoint Access Level Description
GET /api/college-admin/my-roles College Admin Get current admin's sub-roles & permitted tabs
GET /api/college-admin/available-roles College Admin List all available roles (Seeded + Global + Custom Labels)
POST /api/college-admin/admin-roles Super Admin + Unlocked Assign roles to admin user (Blocked when locked)
PUT /api/college-admin/role-tab-config Super Admin + Unlocked Save tab visibility matrix (Blocked when locked)
POST /api/college-admin/role-tab-config/lock Super Admin Lock configuration
POST /api/college-admin/role-tab-config/unlock Super Admin Unlock configuration
PATCH /it-admin/colleges/:id/custom-roles/:key/label IT Admin Customize role display name for a specific college
